# HomeCam

HomeCam — Android-приложение для удалённого просмотра камеры второго собственного телефона.

## Идея

Один и тот же APK устанавливается на оба Android-телефона:

- **Дом** — телефон остаётся дома и ждёт подключения. Камера и микрофон в ожидании выключены.
- **Смотреть** — основной телефон подключается к домашнему по ID и паролю и получает живое WebRTC-видео.

Домашний телефон держит только лёгкую foreground-службу и WebSocket-соединение с signaling-сервером. Камера запускается только на время просмотра и закрывается сразу после отключения.

## Возможности v0.1

- Android → Android.
- Один APK для обоих режимов.
- ID устройства + пароль.
- Камера выключена до начала сеанса.
- WebRTC, видео 720p / 24 fps.
- Аудио.
- Переключение фронтальной / основной камеры.
- Foreground service для режима «Дом».
- Автоматическое завершение камеры при закрытии сеанса.
- signaling-сервер на Node.js/WebSocket.
- GitHub Actions для сборки debug APK.

## Важное ограничение Android

На новых версиях Android доступ к камере из обычного фонового состояния ограничен. Поэтому пользователь один раз включает режим **«Дом активен»**, после чего foreground-служба остаётся активной с системным уведомлением. Сама камера при этом не работает и видео не передаётся.

## Структура

- `app/` — Android-клиент.
- `server/` — signaling-сервер.
- `.github/workflows/android.yml` — автоматическая сборка APK.

## Сборка APK

GitHub Actions запускается при каждом push в `main`/`master` или вручную через Actions → Build Android APK → Run workflow.

После успешной сборки APK находится в artifact `HomeCam-debug-apk`.

## Сервер

В `server/` находится простой Node.js signaling-сервер. Он не хранит и не ретранслирует видео: через него проходят только управляющие сообщения WebRTC. Сам видеопоток WebRTC по возможности идёт напрямую между телефонами.

Для реального использования через интернет сервер нужно разместить на публичном HTTPS/WSS-хосте и указать его адрес в приложении. Для сетей, где прямой WebRTC недоступен, потребуется TURN-сервер.

## Безопасность

Проект предназначен для использования владельцем на собственных устройствах. Он не скрывает системный индикатор камеры и не пытается обходить ограничения Android.
